# Design System

## Logo-Derived Palette

The TRISET logo was inspected directly. Dominant colors:

- Primary blue: `#185B9F`
- Deep navy: `#0B2F5C`
- Dark engineering tone: `#061B35`
- Steel tint: `#C5D6E7`
- Signal red: `#FF0000`

## Tokens

The CSS token system is defined in `styles.css`:

- `--brand-primary`
- `--brand-primary-deep`
- `--brand-primary-dark`
- `--brand-primary-soft`
- `--brand-signal`
- `--ink`
- `--muted`
- `--paper`
- `--surface`
- `--line`
- `--gradient-brand`
- `--gradient-signal`
- `--gradient-steel`
- `--gradient-light`

## Visual Language

The interface uses angular/sharp geometry, red signal accents, blue engineering gradients, technical linework, dark hero environments, service explorers and restrained motion.
